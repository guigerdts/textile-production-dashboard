# 2da official classification is owned by Acabado

Estampado records damages, incidents, and possible origins of second quality, but the official first/second classification belongs to Acabado. Estampado's relation "damage → 2da" is traceability of suspicion, never a formal quality verdict. How Acabado's official data reaches Estampado is not yet defined.

## Consequences

- The dashboard must not expose "mark as 2da" as an Estampado action; it records suspicions and origins for later cross-reference.
